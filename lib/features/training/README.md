# Training

Lesson ladder that feeds the home hero (modules 1–10 and extras).

| File | Role |
|---|---|
| `training_screen.dart` | Ladder UI |
| `training_provider.dart` | Supabase modules + completion |
| `training_models.dart` | `TrainingModuleItem`, lesson sections, image URL helper |
| `lesson_detail_sheet.dart` | One lesson |

Local extras: `assets/data/supplementary_modules.json`. Lesson images often resolve against `AppConfig.websiteOriginWww`.
