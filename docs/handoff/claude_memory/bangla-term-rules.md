Owner's term rules (from the Module 6 wording sheet, 2026-11-15):
- «ডেড» not «মৃত» for a proven-dead line («টেস্টারে ডেড প্রমাণ»).
- Utility acronyms in English letters: LT, HT, 11 kV (not এলটি / এইচটি / কেভি).
- Breaker/switch states as ON / OFF (not অন / অফ); the voice reads them as English words, which is fine.
- Closing an AB switch = «AB লাগানো / লাগালেন», not «AB বন্ধ» («বন্ধ» on a switch reads as OFF — a dangerous ambiguity); «AB না খুলে» for "with AB still closed".

**Why:** owner corrected these across the M6 sheet and approved the AB fix explicitly; consistency with Modules 1–5 («টেস্টারে ডেড প্রমাণ»).
**How to apply:** use these forms in every new draft line and builder prompt (Wave B, Modules 7–10), so the owner doesn't have to fix them again. See [[voice-and-new-text-rules]].
