# Quiz stills

Hourly pack, identify quiz, and some duty/zero-loss options point here.

Name prefixes (not exhaustive):

| Prefix | Topic |
|---|---|
| `img_*` | Drive-export hourly photos (opaque ids) |
| `mat_*` | Materials / tools (helmet, megger, IPC, ACSR…) |
| `mistake_*` | Unsafe acts |
| `proc_*` | Procedure errors (earth, PPE, barrier, feeder) |
| `dtr_*` / `ptr_*` | Distribution / power transformer parts |
| `vcb_*` / `swy33_*` | Breaker / 33 kV switchyard parts |
| `vq_*` | Visual questions (weather, DTR faults, night work) |
| named gear | CT, PT, isolator, LA, relays, bushings |

Keep paths in `hourly_quiz_pack.json` in sync. Do not store answer keys next to these images.
