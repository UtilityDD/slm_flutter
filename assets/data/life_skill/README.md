# Life-skill JSON

`lesson_10_1.json` … `lesson_10_13.json`. Shape:

- `level_id` (`supp_10_N`), `level_title`, `mission_briefing`
- `sections[]` → `title`, `points[]` with `item_name`, `specifications`, `importance`, `daily_check`, optional `image_name` / `image_caption`

Titles: চাপ, সঞ্চয়, মোবাইল/টাকা, শিষ্টাচার, প্রাথমিক চিকিৎসা, ঋণ, বীমা/পিএফ, সন্তানের পড়া, নেশা, খাবার, রাগী গ্রাহক, শ্রমবিধি, সৎ রোজগার.

UI always shows Western digits (`lsDigits`).
