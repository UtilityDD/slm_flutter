# `assets/`

Declared in `pubspec.yaml`. Whole directories are listed so new files in those folders ship without editing pubspec (sounds are listed file-by-file).

| Folder | Used by |
|---|---|
| `data/` | JSON packs (duty slip, quizzes, library, life skill, zero loss, emergency) |
| `data/life_skill/` | 13 life-skill lessons |
| `duty_slip/` | Night-job photos (desk, PTW, callers, van…) |
| `fonts/` | Noto Sans Bengali |
| `lineman/` | Hero figures 00–10 (jpg + webp) |
| `quizzes/` | Hourly / identify / mistake / procedure / equipment stills |
| `safety/library/` | Identify catalog photos |
| `sounds/` | Quiz and field cues |
| `zero_loss/` | Crew portraits + scene layers |

Remote media (lesson posters, some life-skill images) is **not** here; it streams from smartlineman.in.
